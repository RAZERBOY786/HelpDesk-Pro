# HelpDesk-Pro

A modern glassmorphism-styled help desk web application built with React, Vite, and Tailwind CSS v4. Features an interactive ticket queue, self-service knowledge base, incident submission flow, and full settings suite.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- React Router 7
- GSAP (interactive dot-grid background)

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev       # start development server
npm run build     # production build
npm run preview   # preview production build
npm run lint      # run Oxlint
```
